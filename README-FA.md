# مدرسه‌یار دانش‌آموز 1.3.0 — Production Ready Offline First

این نسخه برای استفاده روزمره دانش‌آموز بدون نیاز به اتصال دائم اینترنت طراحی شده است.

## رفتار همگام‌سازی

- بعد از **هر ورود موفق**، اپ به‌صورت خودکار با سرور Sync می‌شود.
- هر بار اپ با یک نشست معتبر باز شود، ابتدا اطلاعات ذخیره‌شده روی گوشی فوراً نمایش داده می‌شود و اگر اینترنت وجود داشته باشد Sync جدید انجام می‌شود.
- در داشبورد دکمه **«بروزرسانی اطلاعات»** وجود دارد و دانش‌آموز هر زمان بخواهد می‌تواند Sync دستی انجام دهد.
- برنامه هفتگی، تکالیف، کارنامه‌ها، حضور و غیاب، اعلان‌ها، منابع و اطلاعات داشبورد روی گوشی Cache می‌شوند.
- Dashboard و داده‌های حساس آزمون با AES/GCM و Android Keystore در حافظه داخلی برنامه ذخیره می‌شوند.
- فایل‌های آموزشی متداول مثل PDF/DOCX/XLSX/PPTX/JPG/PNG/ZIP تا سقف 25MB هنگام Sync برای استفاده آفلاین Prefetch می‌شوند.

## آزمون آفلاین

به‌دلیل سیاست امنیتی مدرسه‌یار، **سؤال‌های آزمون فقط از زمان مجاز شروع آزمون** از Server قابل دریافت‌اند. بنابراین:

1. دانش‌آموز در زمان شروع آزمون باید یک‌بار اینترنت داشته باشد.
2. با ورود/بروزرسانی، پکیج سؤال‌ها و مجوز آزمون خودکار روی گوشی دانلود و رمزگذاری می‌شود.
3. بعد از دانلود، اینترنت می‌تواند قطع شود؛ پاسخ هر سؤال همان لحظه روی گوشی ذخیره می‌شود.
4. در پایان، پاسخنامه قفل می‌شود.
5. اگر اینترنت موجود باشد همان لحظه به Server ارسال می‌شود.
6. اگر اینترنت قطع باشد، پاسخنامه در **صف امن ارسال** باقی می‌ماند و WorkManager با اولین اتصال اینترنت دوباره برای ارسال تلاش می‌کند.
7. Submission Key ثابت است تا Retry باعث ثبت دوباره پاسخنامه نشود.

آزمون‌های MCQ، mixed و پاسخ تایپی تشریحی پشتیبانی می‌شوند. ارسال تصویر پاسخ تشریحی در این نسخه Native اضافه نشده است.

## تکالیف آفلاین و Outbox

خود تکالیف و توضیحات آنها با Dashboard روی گوشی ذخیره می‌شوند و متن پاسخ هنگام تایپ به‌صورت Draft رمزگذاری‌شده باقی می‌ماند. از نسخه 1.2.0، دانش‌آموز می‌تواند حتی بدون اینترنت دکمه ارسال را بزند؛ پاسخ در Outbox رمزگذاری‌شده ذخیره می‌شود و WorkManager با اولین اتصال شبکه آن را خودکار ارسال می‌کند. برای هر ارسال یک `Idempotency-Key` ثابت تولید می‌شود تا Backend بتواند Retryها را بدون ثبت تکراری مدیریت کند. تا زمانی که تکلیف یا پاسخنامه آزمون در صف ارسال است، خروج از حساب مسدود می‌شود تا داده از روی گوشی حذف نشود.

## ساخت APK در GitHub

کل محتوای این پوشه را در ریشه Repository قرار دهید و سپس:

**Actions → Build Android APK → Run workflow**

خروجی:

`Madreseyar-Student-1.3.0-production-debug.apk`

در بخش **Artifacts** همان Workflow قرار می‌گیرد. با ساخت Tag مثل `v1.3.0`، APK در GitHub Releases نیز منتشر می‌شود.
