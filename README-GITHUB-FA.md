# مدرسه‌یار دانش‌آموز 1.3.0 — GitHub APK Builder

این بسته برای ساخت APK روی GitHub Actions آماده است. اپ Native است و به Backend مدرسه‌یار در `https://scooljavanrood.ir/app` متصل می‌شود.

## قابلیت Offline-First
پس از Login، اپ به‌صورت خودکار اطلاعات دانش‌آموز را از Server Sync و روی گوشی ذخیره می‌کند. با بازشدن مجدد اپ نیز Sync تکرار می‌شود. در داشبورد دکمه **«بروزرسانی اطلاعات»** وجود دارد تا دانش‌آموز هر زمان خواست Sync را دستی اجرا کند.

برنامه هفتگی، تکالیف، کارنامه، حضور، اعلان‌ها و سایر اطلاعات دریافت‌شده بدون اینترنت قابل مشاهده‌اند. منابع آموزشی قابل دانلود نیز برای استفاده آفلاین Cache می‌شوند.

آزمون وقتی زمان شروعش برسد از Server دانلود و به‌صورت رمزگذاری‌شده روی گوشی ذخیره می‌شود. بعد از دانلود، آزمون بدون اینترنت قابل انجام است و هر پاسخ همان لحظه روی گوشی ذخیره می‌شود. تحویل نهایی هنگام اینترنت فوراً به Server می‌رود؛ اگر اینترنت قطع باشد پاسخنامه قفل و در صف امن می‌ماند و با اولین اتصال ارسال می‌شود.

## ساخت APK در GitHub
1. ZIP را Extract کنید.
2. محتویات داخل پوشه را در ریشه یک Repository جدید قرار دهید؛ خود ZIP را Upload نکنید.
3. بررسی کنید `.github/workflows/build-apk.yml` در Repository وجود دارد.
4. Commit/Push را روی `main` انجام دهید.
5. وارد **Actions → Build Android APK** شوید.
6. پس از سبز شدن Build، در بخش **Artifacts** فایل `Madreseyar-Student-APK-1.3.0-ProductionReady` را دانلود کنید.

APK داخل Artifact با نام زیر قرار دارد:

`Madreseyar-Student-1.3.0-production-debug.apk`

برای اجرای دستی از **Run workflow** استفاده کنید. اگر Tag مثل `v1.3.0` بسازید، همان APK در GitHub Releases نیز منتشر می‌شود.
