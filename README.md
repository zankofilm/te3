# مدرسه‌یار معلم — Android
نسخه اولیه 1.0.0 اپلیکیشن مستقل معلم، آماده Build در GitHub Actions.

## امکانات نسخه اولیه
- داشبورد روزانه معلم
- کلاس‌های من
- حضور و غیاب
- دفتر نمره و کارنامه مستمر
- تکالیف و تصحیح
- آزمون و تصحیح
- پیام‌ها و اعلان‌ها
- منابع آموزشی و تحلیل کلاس (ورودی رابط کاربری)

این نسخه پایه UI/Navigation اپ معلم است. اتصال endpointهای معلم به سرور در مرحله بعد روی همین پروژه انجام می‌شود.

## Build
از تب Actions، workflow `Build Installable APK` را اجرا کنید. خروجی Artifact با نام `Madreseyar-Teacher-1.0.0-APK` قابل دریافت است.
